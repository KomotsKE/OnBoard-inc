# panel — личный кабинет владельца сайта

React 18 + TypeScript на Vite. Серверное состояние — TanStack Query, маршрутизация —
react-router. Экраны, их эндпоинты и поля описаны в
[docs/screens.md](../docs/screens.md).

## Структура

```
src/
  main.tsx         точка входа: QueryClient → router
  routes.tsx       маршруты и плоский список путей для проверки полноты
  api/client.ts    единственная точка обращения к API
  pages/           по экрану на файл
  components/      переиспользуемые куски UI
  hooks/           хуки TanStack Query
  styles.css       токены оформления
```

## Запуск

```bash
make up                  # поднимает панель вместе со стеком
# http://localhost:5173
```

Vite проксирует `/v1` на API, поэтому в разработке панель и бэкенд оказываются на
одном origin — httpOnly cookie с refresh-токеном работает без CORS
([ADR-0008](../docs/adr/0008-session-storage.md)).

Код смонтирован в контейнер, горячая перезагрузка работает. `node_modules` живут
в томе контейнера: хостовые модули перетёрли бы собранные под alpine.

## Проверки

```bash
make lint      # tsc --noEmit (вместе с ruff бэкенда)
make test      # vitest (вместе с pytest бэкенда)
```

## Что важно знать перед правками

**`fetch` внутри компонента запрещён** (§5 [conventions.md](../docs/conventions.md)):
запросы идут через `api/client.ts` и хуки в `src/hooks/`. Обработка 401 с обновлением
токена появится в `client.ts` в T3.1 — в одном месте, чтобы ни один хук не проверял
срок жизни токена.

**Ошибки API приходят в формате RFC 9457** и превращаются в `ApiError` с полями
`status`, `type`, `title`, `detail`. Логика ветвится по `type`, а не по тексту.

**Токены оформления в `styles.css` общие с виджетом** (`--onboard-*`): превью
подсказки в конструкторе обязано выглядеть ровно так, как она выглядит на сайте
клиента. Разойдутся имена — превью начнёт врать.

**Состояния экрана.** Общие `<Loading/>`, `<ErrorState/>`, `<Empty/>` появятся
вместе с первым экраном, который грузит данные (T3.2): у каждого экрана должны быть
обработаны все три, белый экран при ошибке запроса считается дефектом.

**DOM-тестов пока нет.** Для рендера компонентов понадобятся `jsdom` и библиотека
тестирования — это новые зависимости, их добавляем по согласованию в T3.x. Сейчас
проверяется то, что проверяется без DOM: состав маршрутов и клиент API.

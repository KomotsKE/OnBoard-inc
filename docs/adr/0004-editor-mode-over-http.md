# ADR-0004: Editor-mode общается с платформой по HTTP

Статус: принято · Дата: 2026-10-12 · Задачи: T5.1, T5.2, T5.4, T5.5

## Контекст

Чтобы выполнить обещание «без разработчиков», владелец должен выбирать элементы
мышкой на своём сайте. Панель и сайт клиента — разные origin. Владелец неизбежно
ходит по своим страницам, выбирая элементы для разных шагов, то есть внутри сайта
происходит навигация.

## Решение

Панель открывает новую вкладку с `https://сайт-клиента/...?onboard_edit=<token>`.
Виджет видит параметр, валидирует токен через `GET /v1/public/editor/session?token=…`
и грузит `editor.js`. Каждый добавленный шаг немедленно уходит в
`POST /v1/public/editor/steps` с этим токеном. Панель перезапрашивает шаги на
`window.focus`.

Токен: подписанный HMAC, TTL 15 минут, скоуп — один `tour_id`, права — чтение этого
тура и создание/правка его шагов. Ни панели, ни других проектов, ни аналитики он не
открывает. Токен **не одноразовый**: владелец ходит по своим страницам и перезагружает
их, выбирая элементы для разных шагов, то есть предъявляет токен многократно.
Состояния в БД у него нет, досрочно отозвать нельзя — §9 [data-model.md](../data-model.md).

## Альтернативы и почему отвергнуты

- **`postMessage` между вкладками.** Cross-origin `window.opener` теряется при
  навигации внутри сайта клиента — то есть ровно в основном сценарии работы.
  Состояние конструктора зависело бы от живой связи вкладок.
- **Сайт клиента в `<iframe>` панели.** `X-Frame-Options: DENY` и
  `frame-ancestors` у большинства реальных сайтов делают это неработоспособным.
- **Браузерное расширение.** Отдельный продукт, review в сторах и установка —
  убивает целевую метрику «10 минут до первого тура». Это не гипотетическая цена:
  у Appcues и Userpilot визуальный конструктор работает только через расширение
  Chrome, требует активной сессии в кабинете и не работает на обёрнутых
  Electron-приложениях (§6 [competitors.md](../competitors.md)).

## Последствия

- Выбор элементов устойчив к любой навигации и даже к перезагрузке страницы.
- Появляется публичный эндпоинт, пишущий в БД по токену, — он требует отдельного
  теста на скоуп (чужой тур → 404, просроченный токен → 401).
- Токен живёт 15 минут и не отзывается досрочно. Это принятый риск: прав у него
  ровно на один тур, а таблица ради возможности отзыва в MVP не окупается.
- Нужен fallback: ручной ввод селектора в панели для сайтов, которые нельзя открыть
  в режиме редактора (VPN, авторизация, сложный флоу).

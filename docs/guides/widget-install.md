# Установка виджета на сайт

Инструкция для разработчика сайта, на котором будет работать OnBoard. Всё, что
нужно сделать, — вставить один тег и разрешить домен в панели.

## 1. Вставьте тег

В панели: **Проекты → ваш проект → Установка**. Там готовый тег с ключом вашего
проекта, его можно скопировать кнопкой:

```html
<script src="https://виджет.example/loader.js"
        data-key="pk_…"
        data-api="https://api.example"
        async></script>
```

Место — перед закрывающим `</body>`. Атрибут `async` обязателен: загрузка виджета
не должна задерживать отрисовку вашей страницы.

Тег один и тот же на всех страницах. Ни вызовов вида `identify`, ни второго скрипта
для метрик не требуется: какие туры показывать и где, решает панель.

## 2. Разрешите домен

Там же, на экране установки, добавьте адрес сайта — например `https://example.com`.

**Пока список доменов пуст, виджет не работает нигде.** Это не недосмотр: публичный
ключ виден в исходниках страницы, и без проверки домена им мог бы воспользоваться
чужой сайт. Домены с поддоменами и тестовые стенды добавляйте отдельными строками.

## 3. Проверьте

Откройте любую страницу сайта и вернитесь на экран установки: статус сменится на
«Виджет подключён». Если тур на этой странице опубликован и его условие показа
подходит — он покажется сразу.

## Что это добавляет на сайт

| Вопрос | Ответ |
|---|---|
| Content-Security-Policy | домен файлов виджета — в `script-src`, домен API — в `connect-src`; оба показаны на экране установки |
| Вес | загрузчик не больше 5 КБ в сжатом виде; движок тура (не больше 30 КБ) скачивается только на страницах, где для посетителя есть тур |
| Запросы | один запрос конфигурации на загрузку страницы и события прохождения тура батчами; сторонних доменов виджет не трогает |
| Cookie | ни одной |
| `localStorage` | только прогресс по турам: ключи вида `onboard.v1.<ключ проекта>.tour.<id>` |
| Персональные данные | не собираются: ни IP, ни адрес почты, ни User-Agent посетителя не сохраняются |
| Ваш CSS и DOM | не меняются: интерфейс виджета живёт в Shadow DOM, подсветка рисуется поверх, ваши элементы не трогаются |

## Если тур не показывается

1. **Статус «виджет ещё не найден».** Тег не вставлен или не доехал до продакшена;
   проверьте, что он есть в исходниках страницы.
2. **Статус «подключён», но тура нет.** Проверьте в панели: тур опубликован? Условие
   показа совпадает с адресом страницы? Сравнивается `путь + query`, без домена и без
   `#якоря`, завершающий слэш не важен.
3. **Тур показался один раз и исчез.** Так и задумано при включённом «показывать один
   раз». Очистите `localStorage` сайта, чтобы увидеть его снова.
4. **В консоли сообщения `[OnBoard]`.** Виджет не бросает исключений в вашу страницу:
   обо всех своих проблемах он пишет в `console.debug` с этим префиксом. Сообщение
   оттуда — лучшая подсказка, что именно пошло не так.

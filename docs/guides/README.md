# Инструкции

Короткие пошаговые руководства по окружению — всё, что нужно сделать руками один раз.
Инструкция пишется в той задаче, которая впервые требует этих шагов, а не заранее.

План инструкций:

- `local-setup.md` — поднять стек локально, переменные окружения (задача T0.2)
- `migrations.md` — создать и откатить миграцию (T0.4)
- `widget-install.md` — как клиенту установить виджет на свой сайт (T3.3)
- `e2e.md` — запуск Playwright, установка Chromium (T2.1)
- `publishing.md` — публикация поддеревьев в отдельные репозитории (T0.10)

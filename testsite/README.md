# testsite — стенд для проверки виджета

Статический сайт, на котором проверяется встраиваемый виджет. Отдаётся nginx из
`docker-compose.yml` на `http://localhost:8080`.

## Зачем нужен

Виджет работает на чужих страницах, про CSS которых мы не знаем ничего. Стенд —
это намеренно враждебная среда: глобальные сбросы стилей, `!important`,
sticky-хедер, модалка, элемент, появляющийся через две секунды, и SPA-навигация без
перезагрузки. Если виджет корректен здесь, он корректен почти везде.

## Запуск

```bash
make up                     # поднимает стенд вместе с остальным стеком
curl -I localhost:8080      # 200 OK
```

Файлы монтируются в контейнер только для чтения, поэтому правка `index.html`
видна после перезагрузки страницы — пересобирать контейнер не нужно.
